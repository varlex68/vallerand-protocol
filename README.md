# vallerand-protocol
Protocole métrologique et suite d'inférence pour l'Infomécanodynamique (DOI: 10.5281/zenodo.22969532). Analyse comparative (N=100) du Processus Circulaire Invariant (PCI), de la Pression Formelle (w = -1) et de l'effondrement d'impédance (β → 0) face aux approches stochastiques.
